开始前知道这几件事

  • 准备自己的微信、飞书账号，以及一条愿意测试的资料。密钥只从你自己的开通消息获取；不要提交到这个网页。
  • 已接好飞书就复用。首次定时同步从启用时建立基线，只处理之后新发现的资料；飞书使用通用内容创作模板，手动和定时共用记录规则。
  • 本地定时任务需要电脑和 Agent 客户端可用。只有后台试跑、文档读回和重复运行去重通过，才算启用成功。
  • 网页、操作图片和完整 ZIP 均从当前域名提供。Agent 后续安装工具与授权时，会按官方指引访问相应服务。
